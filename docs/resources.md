# Resources

Free and official resources for learning to defend Windows and Linux systems. This page
replaces the PDFs and tools that used to be bundled in the repository, so everything here comes
from its official source and stays current.

## Competition

- [CyberPatriot](https://www.uscyberpatriot.org/): rules, schedules and training materials
  for registered teams

## Hardening guidance

- [CIS Benchmarks](https://www.cisecurity.org/cis-benchmarks): free, detailed hardening guides
  for Windows, Ubuntu, Debian, browsers and more. They're the basis for most of the numbers in
  the [checklists](guides/windows-hardening.md).
- [CIS-CAT Lite](https://learn.cisecurity.org/cis-cat-lite): free tool that scores a machine
  against a CIS Benchmark
- [Microsoft Security Compliance Toolkit](https://www.microsoft.com/en-us/download/details.aspx?id=55319):
  Microsoft's security baselines, plus LGPO and Policy Analyzer
- [DISA STIGs](https://public.cyber.mil/stigs/): US Department of Defense configuration guides
- [Windows security documentation](https://learn.microsoft.com/windows/security/)
- [Ubuntu Server documentation](https://documentation.ubuntu.com/server/) and
  [Ubuntu security](https://ubuntu.com/security)

## Tools

- [Sysinternals](https://learn.microsoft.com/sysinternals/): Autoruns, Process Explorer, TCPView
  and more, straight from Microsoft
- [Lynis](https://github.com/CISOfy/lynis): Linux security auditing tool
- [CyberChef](https://gchq.github.io/CyberChef/): decode, decrypt and analyze data in the browser
- [explainshell](https://explainshell.com/): paste a Linux command and see what each part does
- [SS64](https://ss64.com/): command reference for cmd, PowerShell, bash and more
- The CSSR [audit scripts](audit-scripts.md)

## Learning

- [*The Linux Command Line*](https://linuxcommand.org/tlcl.php) by William Shotts: free book
- [OWASP](https://owasp.org/): web application security, including the Top 10
- [SANS cheat sheets](https://www.sans.org/blog/the-ultimate-list-of-sans-cheat-sheets/):
  PowerShell, Windows command line, Linux and more
- [Cisco Networking Academy](https://www.netacad.com/): free networking courses and Packet Tracer
