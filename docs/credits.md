# Credits

From 2018 to 2020 this repository held copies of other people's work: zip downloads
of other teams' GitHub repos, scripts from blogs and gists, checklists from coaches.
Most of that has been removed. Each copy was replaced by a link to the original,
so the authors get the credit and visitors get the current version.

A few pieces are still in [`legacy/`](legacy.md) because the old entry scripts call them
and their licenses allow copying. They are marked **kept** below and ship with their
license files.

!!! note "Correction"
    Earlier versions of this repository showed Ethan Aldrich's name in the banners of two of
    Ethan Fowler's scripts (`Windows.bat` and `Linux_Ubuntu.sh`), and a copy of the Wellesley
    team's `main.sh` was missing its copyright line. Both scripts are Ethan Fowler's (Team-ByTE),
    and the Wellesley header has been restored in `legacy/linux/dofirst/main.sh`.

If you wrote something listed here and the link or credit is wrong, please
[open an issue](https://github.com/0x000NULL/CSSR/issues).
